၁။ Script အတွက် ID စည်းမျဉ်း
- Script တွင် အသုံးပြုမည့် object identifier တစ်မျိုးတည်းမှာ Unity PathID ဖြစ်ရမည်။
- ClassID၊ TypeIndex၊ DataOffset၊ ByteSize၊ RVA၊ MetadataToken တို့ကို ဒုတိယ object identifier အဖြစ် မသုံးရ။
- Name နှင့် မူရင်း serialized property/key များကို မူရင်းစာလုံးပေါင်းအတိုင်း ထိန်းသိမ်းရမည်။
- GitHub objects.csv တွင် PathID တစ်ခုစီသည် ထပ်မနေကြောင်း စစ်ဆေးတွေ့ရှိသည်။ သို့သော် objects.csv တွင် မူရင်း container အမည် column မပါ။
- ထို့ကြောင့် Local Source ရှာဖွေရာတွင် PathID ကိုသာ object ID အဖြစ်သုံးပြီး မူရင်း container filename ကို source-location scope အဖြစ် သီးခြားမှတ်တမ်းတင်ရမည်။ Container filename ကို ဒုတိယ object ID ဟု မသတ်မှတ်ရ။
- Container မသေချာပါက UNKNOWN ဟုထားရမည်။ မခန့်မှန်းရ။

၂။ ပင်လယ်ရေပြင်နှင့် တိုက်ရိုက်ဆက်စပ်နိုင်သည့် အထောက်အထား
- C# metadata ထဲတွင် Ceto.ProjectedGrid နှင့် Ceto.Ocean ရှိကြောင်း အတည်ပြုထားသည်။
- Ceto.ProjectedGrid တွင် CreateGrid, UpdateGrid, UpdateBounds, ApplyProjection စသည့် method အမည်များရှိသည်။
- Ceto.Ocean တွင် Update, UpdateOceanScheduler, CalculateWindDirVector, SunDir, SunColor, RenderWaveOverlays, RenderReflection စသည့် method အမည်များရှိသည်။
- Ceto.WaveSpectrum / FourierCPU / FourierGPU / PhillipsSpectrum / UnifiedSpectrum ဆိုင်ရာ code metadata ရှိသည်။
- Vulkan GLSL entry shader များထဲတွင် Ceto_ButterFlyLookUp နှင့် Ceto_ReadBuffer0 ဟူသော မူရင်း shader property key များကို တွေ့ရသည်။ ဤ shader များသည် Fourier processing အတွက်ဖြစ်ကြောင်း code နှင့် shader text က ထောက်ခံသည်။
- ဤ Ceto class/method metadata များသည် C# code metadata ဖြစ်ပြီး Unity serialized object PathID မဟုတ်ပါ။ Script ၏ object selector ထဲသို့ RVA/MetadataToken မထည့်ရ။
