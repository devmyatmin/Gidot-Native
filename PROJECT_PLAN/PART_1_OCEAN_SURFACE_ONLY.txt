ပင်လယ် Full Project — Master Plan
PART 1 — ရေပြင် ONLY
မှတ်တမ်းအမျိုးအစား: အတည်ပြုထားသော Project လမ်းညွှန်
ရည်ရွယ်ချက်: မူရင်း Stranded Deep ပင်လယ်ရေပြင်ကို မူရင်းပုံစံအတိုင်း ပြန်လည်တည်ဆောက်နိုင်ရန် GitHub Repo ထဲရှိ မူရင်းအချက်အလက်များကို ရှာဖွေမှတ်တမ်းတင်ပြီး Local Original Source မှ အသစ်ပြန်ထုတ်ရန်။

၁။ အဟောင်းအသုံးပြုမှုကို ပိတ်ပင်ခြင်း
- အဟောင်း Godot Project ကို မသုံးရ။
- အဟောင်း Asset များကို မသုံးရ။
- အဟောင်း Python Script များကို မသုံးရ။
- အဟောင်း OBJ၊ PNG၊ BIN နှင့် အခြား Export လုပ်ပြီးသားဖိုင်များကို မူရင်းအသစ်ထုတ်လုပ်မှုအတွက် မသုံးရ။
- အသစ်သီးသန့် Godot Project ကို တည်ဆောက်ရမည်။

၂။ GitHub Repo မှ ရှာဖွေမှတ်တမ်းတင်ခြင်း
- GitHub Repo: https://github.com/devmyatmin/Gidot-Native
- GitHub ကို မူရင်းအချက်အလက်များ ရှာဖွေသတ်မှတ်ရန် Reference အဖြစ်သာ အသုံးပြုရမည်။
- Script တွင် ID အမျိုးအစား တစ်မျိုးတည်းကိုသာ အသုံးပြုရမည်။
- မူရင်းပုံသေ Key များကို မူရင်းအတိုင်း ထိန်းသိမ်းရမည်။
- ID၊ Key၊ Name နှင့် Value များကို မခန့်မှန်းရ၊ မပြောင်းရ၊ မပေါင်းစပ်ရ။
- ID တစ်ခုနှင့် သက်ဆိုင်သော မူရင်းအချက်အလက်များကို အတူတကွ ချိတ်ဆက်မှတ်တမ်းတင်ရမည်။
- မသေချာသောအချက်ကို မသေချာကြောင်း သီးခြားဖော်ပြရမည်။

၃။ လုပ်ဆောင်မည့် နယ်ပယ်
- ပင်လယ်ရေပြင် ONLY။
- ရေအောက်ပိုင်း၊ ကမ်းခြေ၊ ကျွန်း၊ Gameplay Logic နှင့် အခြားစနစ်များကို PART 1 ထဲသို့ မထည့်ရ။
- ရည်မှန်းချက်မှာ မူရင်းပင်လယ်ရေပြင်၏ ပုံစံနှင့် အပြုအမူကို မူရင်းအချက်အလက်အပေါ် အခြေခံ၍ ပြန်လည်တည်ဆောက်ရန် ဖြစ်သည်။

၄။ ထုတ်လုပ်မှုနည်းလမ်း
- အရာအားလုံးကို တစ်ခါတည်း ထုတ်ရန် မလို။
- အစိတ်အပိုင်းတစ်ခုချင်းစီကို သီးခြားအသစ်ထုတ်လုပ်နိုင်သည်။
- ထုတ်ပြီးသော အစိတ်အပိုင်းများကို စစ်ဆေးပြီး နောက်ပိုင်းတွင် ပြန်လည်ပေါင်းစပ်ရမည်။
- နောက်ဆုံးတွင် အသစ်တည်ဆောက်ထားသော Godot Project ထဲသို့ ထည့်သွင်းအသုံးပြုနိုင်ရမည်။

၅။ လမ်းကြောင်းမပြောင်းရ စည်းမျဉ်း
- PART 1 ၏ ပန်းတိုင်သည် “မူရင်းပုံစံအတိုင်း ပင်လယ်ရေပြင် ONLY ကို အသစ်ပြန်ထုတ်လုပ်ခြင်း” တစ်ခုတည်း ဖြစ်သည်။
- အတည်ပြုပြီးသော ဤစည်းမျဉ်းများကို ကိုယ့်သဘောဖြင့် မပြောင်းရ။
- အခြား Project၊ အခြားနယ်ပယ် သို့မဟုတ် မသက်ဆိုင်သော အလုပ်သို့ အလိုအလျောက် မကူးရ။
- လက်ရှိအဆင့် မပြီးမချင်း နောက်အဆင့်သို့ မကူးရ။
- လမ်းကြောင်းပြောင်းရန် လိုအပ်ပါက အလုပ်ကို ရပ်ပြီး အသုံးပြုသူ၏ ခွင့်ပြုချက်ကို အရင်ရယူရမည်။
- အတည်ပြုပြီးသော အလုပ်ကို အကြောင်းမရှိဘဲ ပြန်ဖျက်ခြင်း၊ ပြန်စခြင်း၊ ပြန်ပြောင်းခြင်း မပြုရ။

ဤမှတ်တမ်းသည် PART 1 အတွက် အဓိကလမ်းညွှန်ဖြစ်သည်။ နောက်ဆက်တွဲလုပ်ဆောင်မှုတိုင်းသည် ဤပန်းတိုင်နှင့် စည်းမျဉ်းများကို လိုက်နာရမည်။
